新增股票

尚未同步 GitHub。按「同步 GitHub」即可載入最新清單。

使用說明

① 按「同步 GitHub」載入正式股票清單。

② 新增、刪除或修改股票代碼時，系統會透過 Cloudflare Worker 更新 GitHub。

③ 股票名稱由 stocks.json 查詢；查不到時可手動輸入。

④ 修改中文名稱會保存在目前瀏覽器，不會直接修改 GitHub 的 stocks.json。

⚠️ 每次需要 API 時才會要求管理金鑰。請勿將金鑰寫入程式碼或分享給他人。

⚠️ 成功觸發 GitHub Actions 不代表股票分析已完成，請到 GitHub Actions 確認執行結果。
